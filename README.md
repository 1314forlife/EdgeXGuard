\# EdgeXGuard



基于RK3588的边缘智能安防网关。



\## 功能

\- 实时监控 (RTSP拉流)

\- AI目标检测 (YOLO + NPU)

\- 环境监测 (温湿度 + PIR)

\- 远程控制 (手机/PC)

\- 智能联动 (规则引擎)
